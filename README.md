# 🎨 AI Image Generator App

## 📌 Project Overview
An interactive web application built with Python and Gradio that allows users to generate custom AI images on-the-fly from text prompts. It connects dynamically to the Pollinations.ai API without requiring complex local model setups or paid API keys.

## 🛠️ Tech Stack & Libraries
* **Programming Language:** Python
* **Web Interface:** Gradio (`gradio`)
* **API Requests & Media Handling:** `requests`, `Pillow` (PIL), `urllib`
* **Tools:** Git, GitHub, VS Code
